# First Post

This is the beginning of a new content system.

## Architecture

The filesystem serves as the primary organizational structure. Content lives in `/content` directories organized by type:

- `/content/pages` - Static pages like the homepage
- `/content/posts` - Blog posts with dates and tags
- `/content/projects` - Project showcases with status metadata

## Key Principles

1. **Git-native workflow** - Content changes through file editing
2. **Zero CMS** - No database or admin panel needed
3. **Static-first** - Optimized for Cloudflare Pages deployment
4. **Sequential reading** - Typography-first design for long-form content
