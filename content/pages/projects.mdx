<Project
  title="writing-rag"
  href="https://github.com/kexec-run/writing-rag"
  position="creator"
  period="2026 - present"
  stack={["python"]}
>
  - I built writing-rag to use chats, transcripts, and existing writing as memory for guided article generation.
  - Conversational context stays separate from examples of my own writing.
  - Qwen retrieves source material; local models generate drafts using author-provided scaffolding, followed by claim and formatting checks.
  - Experiments cover conversation grouping, embeddings, text selection, reranking, and narrative structure.
  - Work in progress, with working synthetic demos and a documented experiment history.
</Project>

<Project
  title="cv-to-job"
  href="https://github.com/kexec-run/cv-to-job"
  position="creator"
  period="2026 - present"
  stack={["python", "javascript"]}
>
  - I built cv-to-job to reduce repetitive signup forms, repeated data entry, and CV tailoring across job websites.
  - An AI agent uses a CV and saved answers to prepare documents, fill forms, and track applications.
  - Validation, duplicate checks, and application records run in code to reduce guessing and unsupported claims.
  - Multiple agents can coordinate through file locking and job ownership.
  - Private CVs, credentials, and application history stay outside the public repository.
</Project>
