# kexec.run

- I built this website so content paths define routes and MDX defines page composition.
- A file at `content/posts/linux/example.mdx` becomes `/blog/linux/example`.
- Pages can embed other pages, post lists, and curated project entries directly in MDX.
- Tags are generated from content and project technology lists.
- Built as static files and hosted on Cloudflare Workers.
