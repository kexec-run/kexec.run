# cv-to-job

[GitHub](https://github.com/kexec-run/cv-to-job)

- I built cv-to-job to reduce repetitive signup forms, repeated data entry, and CV tailoring across job websites.
- An AI agent uses a CV and saved answers to prepare documents, fill forms, and track applications.
- Validation, duplicate checks, and application records run in code to reduce guessing and unsupported claims.
- Multiple agents can coordinate through file locking and job ownership.
- Private CVs, credentials, and application history stay outside the public repository.
